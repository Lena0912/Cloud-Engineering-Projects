# ☁️ Cloud Engineering & AWS Projects

This repository documents my hands-on experience with Amazon Web Services (AWS) and cloud infrastructure management.

## 🚀 Projects Overview

### 1. Static Website Hosting (S3 + CloudFront)
- **Goal:** Deploy a highly available and fast-loading static website.
- **Tools:** AWS S3, CloudFront (CDN), Route 53, ACM (SSL/TLS).
- **Outcome:** Secured the site with HTTPS and improved global loading speed using edge locations.

### 2. Infrastructure Management (EC2 & Security)
- **Goal:** Launch and secure a Linux-based server.
- **Tools:** Amazon EC2, Security Groups, IAM Roles, SSH Keys.
- **Key Action:** Implemented **Least Privilege** by restricting SSH access (Port 22) to specific IP addresses.

### 3. Monitoring & Automation
- **Tools:** CloudWatch, AWS Lambda (Basic workflows).
- **Implementation:** Created CloudWatch Dashboards to monitor CPU utilization and set up Billing Alarms to manage costs.

## 🛠️ Technical Skills Demonstrated:
- **Identity & Access Management (IAM):** MFA policies, Roles, and Users.
- **Storage:** S3 Bucket Policies and Lifecycle Rules.
- **Networking:** VPC basics, Security Groups, and CloudFront distributions.
